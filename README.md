# Saudi Prayer Times

A simple and modern prayer times website for cities across Saudi Arabia.

## Features

- Displays daily prayer times.
- Supports multiple Saudi cities.
- Updates the city name and date automatically.
- Fetches prayer times using the AlAdhan API.
- Clean and responsive Arabic interface.
- Built with HTML, CSS, and JavaScript.

## Supported Cities

- Al Qassim
- Dammam
- Riyadh
- Jeddah
- Makkah
- Madinah
- Taif
- Tabuk
- Hail
- Jazan

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Axios
- AlAdhan Prayer Times API

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Choose a city from the city selector.
4. The prayer times will update automatically.
